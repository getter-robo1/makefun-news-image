A pure Python 3 standard-library program that draws one 1024x1024 newspaper
front page summing up the world news of Tuesday 24 November 2026: the COP31
deadlock in Antalya, the Hormuz deaths, Russia's warning to Estonia, the
Banten factory fire, India's pledge to Nepal, the Kyiv strikes and the
burning Sparta II, plus the day's sport and science.

Run it locally:

```
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

It writes `out/entry.png` with no network, and two runs write identical bytes.
